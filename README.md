A tiny Node program that writes one short text to `/output/entry.txt` — a status page line an AI agent would publish while a total server outage is under way. All services are down, the agent doesn't know why yet, and it can't check the logs because the logging service is down too. Plain, first person, honest about the uncertainty. 139 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
